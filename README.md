# verinoo-node

**Rust testnet node for [Verinoo](https://verinoo.com) — an AI chain network.**

Status: **Phase R0 — types + conformance foundation.**

| Crate | Purpose |
|---|---|
| `types` | Canonical codec, tx model — byte-parity with the reference client |
| `conformance` | Golden-vector tests generated by the TS oracle |
| *(next)* | `state` (RocksDB), `exec`, `consensus` (LeaderPolicy → Malachite), `network` (libp2p), `zk` (native witnesses + rapidsnark + ark-groth16), `rpc`, `node` |

The TypeScript repository ([iguha0/Verinoo](https://github.com/iguha0/Verinoo))
is the **reference client**: its engine defines validation semantics, and its
test-suite exports the golden fixtures this workspace must reproduce exactly.
See `crates/conformance/fixtures/`.

```bash
cargo test        # conformance against committed fixtures
```

AGPL-3.0. Research prototype.
